## Context anchors (load-bearing — read before planning any task)

- **Engine version:** `engine/model.py` → `MODEL_VERSION = "2.5.0"`, `COMPUTE_SCHEMA_VERSION = "1.3.0"`, `EXAMPLE_BUILDING_SQFT = 10000`. The 10k example is the **golden anchor** — every 10k fixture is byte-for-byte; the recalc/frozen-fixture gate is **CI-blocking**. Do NOT regenerate goldens at 12,500.
- **#245 just shipped** (engine 2.5.0): the Utilities/trash line is now derived as `UTILITIES_PER_SQFT × building_sqft`; the default cost seed scales Equipment & Fixtures (`FIXTURES_PER_SQFT 4.50`) + Build-out (`BUILDOUT_PER_SQFT 5.00`) per sq ft. The wizard already has `setBuildingSqft`/`reseedScaledCostRows` machinery. **This redesign reuses that machinery and changes only the wizard-side default (12,500/80% supersedes 10,000/70%).**
- **Clerk auth just went live** — Clerk user identity is now available to the app. The satellite holds NO Clerk secret (`app/clerk/verify.py` is JWKS-public-key-only).
- **Penny ships dark** (`AI_DISABLED`). The shell mounts but the AI is off. Every Penny-AI-dependent behavior must ship a deterministic AI-off fallback now and gate the AI behavior behind the flag.
- **Router is hand-rolled** (`web/src/router/route.ts` + `App.tsx` `parseRoute` + `useSyncExternalStore`/popstate). Do NOT add react-router. Wizard steps are an internal cursor in `useWizardState`, not routes — page-per-step requires extending this router FIRST.
- **Feedback redaction** (`app/feedback/redact.py`): `SAFE_CONTEXT_KEYS` allowlist strips email, `$`, `%`, links, secrets, slugs from everything GitHub-bound (issues are "safe-if-public").
- **Terms gate is a hard rule** (PRD §21): `termsAccepted` gates export/share; `EXPORT_DISCLAIMER` is stamped into `.xlsx` + Board Packet by `engine/model.py`.
